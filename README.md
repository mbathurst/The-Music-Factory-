# The Music Factory

Elementary music classroom website for Miss Bathurst.

## GitHub Pages

The repository includes a GitHub Actions workflow that unpacks `music-factory-website.zip` and deploys the complete site to GitHub Pages whenever `main` is updated.

If Pages has not yet been enabled for the repository, open **Settings → Pages** and choose **GitHub Actions** as the source. After that, pushes to `main` will deploy the site automatically.

The deployed site contains:
- Home
- Calendar
- Music & Practice
- Contact
- Responsive navigation
- Music Factory branding and logo assets
